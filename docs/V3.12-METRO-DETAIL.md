## Why integration is separate
The V3.9.2 root README documents that the live TypeScript game source is restored from 22 checked archives by `bootstrap.mjs`. Therefore we cannot safely guess an import path or replace the main game's world layout without inspecting the restored source and its navigation / collision invariants.

## Integration outline
1. Unpack the verified payload locally with `node bootstrap.mjs`.
2. Inspect `apps/client/src/main.ts` and its world / map builder.
3. Verify whether the detail-file path is inside the restored tree. Keep the new module as a tracked source file outside of the archive, and do not let a build step overwrite it.
4. Import `buildMetroStationDetail` into the actual scene builder and attach the returned `group` once per station load:
   ```ts
   import { buildMetroStationDetail } from './world/MetroStationDetail'; // adjust relative path
   const metro = buildMetroStationDetail({ seed: 7129, debris: true, shadow: true });
   scene.add(metro.group);
   ```
5. Replace or suppress any overlapping preexisting placeholder subway geometry first; this module deliberately constructs a whole station in a 50m by 25m footprint.
6. Reconcile `metro.solidBounds` with the game's authoritative physics/nav collision representation. Avoid adding the same wall/floor twice.
7. On level unload: remove `metro.group` from the scene and run `metro.dispose()`. Do not dispose while reused assets are attached.
8. Run the existing tests, TypeScript/Vite build and a browser smoke test; validate player stair travel, platform edge behavior, shooting raycasts and zombie navigation.
9. Measure CPU/GPU frame times on target desktop hardware and optimize visibility, draw calls, geometry merge and instancing before deploying.

## Geometry included
Actual structural depth for two platform islands, columns, beams, stairs and handrails, track sleepers, rails, fasteners, ventilation ducts, light housing, exposed utilities, electrical boxes, safety strips and scattered rubble. The model is synthetic/parametric and does **not** pretend to be a hand-sculpted AAA GLB asset.

## Important follow-up
The module builds relatively many discrete draw calls. The rail fasteners are instanced; for production, merge static meshes by material or use repeated InstancedMesh batches. Navigation meshes and server collision must be regenerated from the final layout.
